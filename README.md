Описание проекта

Это консольное Java-приложение для работы с коллекцией автобусов.
Программа позволяет создавать, валидировать, сортировать и обрабатывать данные об автобусах, 
используя различные подходы заполнения и алгоритмы сортировки.

Функционал приложения

Приложение поддерживает:

Ручной ввод данных
Генерацию случайных автобусов
Загрузку данных из файла
Заполнение через Stream API
Многопоточный подсчёт элементов
Сортировку по разным полям
Запись результата в файл
Модель данных

Класс Bus содержит:

номер (number)
модель (model)
пробег (mileage)

Реализован через Builder Pattern, что обеспечивает:

удобное создание объектов
гибкость расширения
читаемость кода

Архитектура проекта
Основные компоненты:
Bus — модель данных (Builder)
BusSortingApp — основная логика приложения
BusCollection — кастомная коллекция
SortStrategy — интерфейс стратегии сортировки
реализации сортировок: SortByNumber \ SortByModel \ SortByMileage \ SortByMileageEvenOnly
DataValidator — проверка входных данных
BusCounterThread — многопоточность
FileWriterUtil — запись результата в файл

Паттерны проектирования
1. Strategy Pattern

Используется для сортировки: SortStrategy sortStrategy; sortStrategy.sort(buses);

Позволяет динамически выбирать алгоритм сортировки.

2. Builder Pattern

Используется в классе Bus:

new Bus.Builder()
    .setNumber(...)
    .setModel(...)
    .setMileage(...)
    .build();
Сортировка

Реализованы 4 варианта сортировки:

по номеру (лексикографически)
по модели
по пробегу
особая сортировка:
чётные значения сортируются нечётные остаются на месте
Stream API

Заполнение массива реализовано через:

IntStream.range()
функциональное создание объектов
кастомную коллекцию BusCollection
Многопоточность

Реализован класс:

BusCounterThread

Функции:

запуск отдельного потока
подсчёт количества автобусов с заданным mileage
использование start() и join()

Работа с файлами
Вход:
чтение из buses.txt
Выход:
запись в sorted_buses.txt

Режим записи: append

Валидация данных

Класс DataValidator проверяет:

номер не пустой
модель не пустая
пробег ≥ 0

Логика работы приложения

Запускается main()
Создаётся объект BusSortingApp
Запускается метод start()
Включается цикл while(true)
Показывается меню
Пользователь выбирает:
способ заполнения
стратегию сортировки
Выполняется обработка данных
Результат выводится в консоль
Данные записываются в файл
Возврат в меню

Выход — только через пункт 0.

Тестирование

В проекте реализованы тесты:

BusTest — тест модели
DataValidatorTest — тест валидации
SortStrategyTest — тест сортировок
BusSortingAppTest — тест сценариев приложения

Ограничения

запрещено использовать готовые сортировки Java (Collections.sort, Arrays.sort)
сортировки реализованы вручную (bubble sort)
кастомная реализация коллекции
упор на ООП и паттерны
